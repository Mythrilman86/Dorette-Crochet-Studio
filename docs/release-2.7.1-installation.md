# Dee's Crochet Studio v2.7.1 — installation and recovery

These instructions describe the intended successor packages. Do not distribute preparation outputs; use the separately approved release packages and their published SHA-256 checksums.

## Back up first

Export chart-library ZIP, Settings/Layout JSON, Written Pattern .deewritten files with their PDFs, and Pattern Creator .deepattern files. Store copies outside application/browser storage. Do not overwrite your only backup.

## Android

The planned APK is Dees-Crochet-Studio-2.7.1-Android.apk, application ID com.deescrochetstudio.app, version code 34. Confirm its checksum and unchanged signing identity before installing. Keep the existing app installed and choose Update; do not uninstall or clear storage. Prior public code 23 and private/candidate codes 32/33 require an in-place upgrade validation against the final signed APK. Source tests alone do not certify that APK.

## Windows

Stop the old folder normally after saving and backing up. Extract Dees-Crochet-Studio-2.7.1-Windows.zip into a separate permanent folder. Use the existing browser profile and http://127.0.0.1:17828 address. If offered, wait for preparation and choose Save and update. Never clear site data to update. Retain the previous folder and backups as recovery options.

## Website and offline use

Remain online until Ready for offline use. Verify projects and needed PDFs reopen offline before relying on disconnected access. A new content-derived cache identity separates the successor runtime from the prepared v2.7.0 cache; changing versions does not change project storage origins or backup schemas.

If an update or save fails, preserve the current installation/profile and external backups. Do not clear storage as a troubleshooting step. Restore supported backups as separate copies and confirm their contents before replacing any working project.
