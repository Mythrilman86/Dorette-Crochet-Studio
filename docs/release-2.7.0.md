# Dee’s Crochet Studio v2.7.0

More control over your photo charts, more comfortable crochet tracking, and two usable Beta tools for writing and publishing your own patterns.

## What’s new

- **80 × 110 project preset.** In Studio → Projects, open the dimensions/starter-template menu and choose 80 × 110 for 80 columns, 110 rows and 8,800 stitches. Existing presets and manual dimensions remain available. Selecting a preset does not resize an existing chart.
- **Crop to Fill.** Frame the photograph for your chart, move the proposed crop before confirming it, and keep the subject where you want it. Cancel, Reset and Undo Crop remain available.
- **Photograph beside stitches.** Compare the framed photograph with the actual stitch preview before applying the result. Preview and Discard leave saved stitches intact.
- **Grayscale and optional Cartoon preparation.** Compare more shade choices, adjust tones and choose optional local preparation. More shades can preserve more detail but require more yarn changes. Small facial details may still need manual editing.
- **Easier zoom and navigation.** Type a zoom percentage, use more predictable wheel zoom, collapse chart tools, and use controls that fit phones, tablets and laptops. Helpful chart guidance stays outside the stitches.
- **Row-based crochet tracking.** Complete a row and move to the next while keeping the advanced stitch controls available. Progress, Undo/Redo and reopening remain supported.
- **More local photo imports.** Supported images are checked and prepared on your device. HEIC/HEIF needs a supported Android decoder; otherwise export a JPEG or PNG copy. Animated images use a still frame.
- **Pattern Creator (Beta).** Write original instructions, attach images, retain reviewed frozen snapshots and export editable .deepattern backups. Restore as Copy keeps an independent draft.
- **PDF Publisher (Beta).** Prepare Graph / Colorwork publications from reviewed snapshots in Letter or A4, with supported charts, yarn legends, authored text and selected photographs. Other pattern families do not yet have every professional PDF layout.

Beta features are available to use and are still being improved. Back up important projects regularly. Experimental Keep Detail research is not included.

Existing Studio editing, Paint/Fill/Pick, Pattern Lock, project organization, Written Pattern Companion, offline work and separate project/settings backups remain available.

## Install or update

Android: download **Dees-Crochet-Studio-2.7.0-Android.apk** from this release and choose Update over the existing app. This candidate uses Android code 33 with the established application/signing identity. Keep the existing app installed; do not uninstall or clear its storage. Private Build 32 users already see version 2.7.0, so they must select the newer APK manually; the version-name-based automatic check does not advertise another 2.7.0 build.

Windows: download **Dees-Crochet-Studio-2.7.0-Windows.zip**, extract it to a separate folder and run **Open Dee’s Studio.cmd**. Use the same regular Edge/Chrome profile and **http://127.0.0.1:17828**. Stop the previous folder normally first. If offered, wait for preparation and choose **Save and update**. Do not clear browser storage. Keep all extracted program files together.

## Protect your work

Before updating, retain external copies of Studio project ZIPs, Settings and Layout JSON, Written Pattern .deewritten backups with their original PDFs, and Pattern Creator .deepattern backups. These are separate backup systems. A finished PDF is not an editable project backup. Keep backups private.

Keep the previous Windows folder for recovery. Android downgrade to an older code may be blocked and is not a guaranteed data-safe rollback. If an update is rejected or records look wrong, stop and retain the installation and backups.

## Offline use and known limits

Stay connected during website setup until Studio reports **Ready for offline use**, then verify reopening offline. An intermittent Chromium first-install service-worker issue remains under investigation; refreshing or retrying while online can recover setup. This release does not claim its root cause is fixed. Safari/iOS physical acceptance is not established by this release-candidate work.

Photographs are processed locally. Update checks and downloads may contact GitHub; local processing does not mean the app never makes network requests. This is a direct-download GitHub/website release, not a Google Play submission.
