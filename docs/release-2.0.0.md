# Dee’s Crochet Studio 2.0.0

- Use the screen-filling Crochet View to select stitches, mark rows, see progress and change direction and contrast.
- Straighten and adjust chart photos offline, review marked regions, and confirm suggestions against the pattern legend. Fabric comparison is experimental guidance.
- Browse expanded illustrated instructions, explain a selected chart row locally, and explicitly search Wikimedia Commons for references. Saved links remain available offline.
- Pin projects separately from Favorites, manage custom categories, and restore projects from the Recycle Bin. Full ZIP backups preserve this organization data. Native project sharing sends the same portable ZIP format through the device share sheet.
- Back up all projects before updating from 1.8.4. On Android, use Updates when the GitHub release becomes available, or open the signed APK from Files with the existing app still installed. Android requires installation confirmation. On the website, use Save and update Studio when prompted.
- iOS simulator builds are checked in CI. Device distribution requires Apple signing and provisioning. Production OCR, a fabric classifier, cloud AI, and cloud sync are deferred. There are no new recurring operating costs.

See [the scanner benchmark](../benchmark/README.md) for sources, limitations, and the before-and-after comparison.
