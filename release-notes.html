Dee's Crochet Studio 2.7.2

Windows and website update improvements. Save checks protect in-progress work before applying an update. Windows verifies and stages official update packages; the website prepares offline files before asking to update.

Back up before updating

Keep chart-library ZIP, Settings & Layout JSON, Written Pattern .deewritten backups with original PDFs, and Pattern Creator .deepattern backups outside browser storage. These are separate formats; there is no automatic cross-device synchronization.

Windows

Older packages need one manual move to this package. Keep the same Windows account, browser profile and http://127.0.0.1:17828 address. Keep the old folder and backups. Later compatible application-resource updates can use Save & Update; helper changes may still require a manual package transition.

iPhone

Use your existing Safari tab or Home Screen icon. Save and back up first, close other Studio pages, and select Save & Update when offered. Wait for version 2.7.2 and Ready for offline use. Never clear site data or remove the icon to update.

The older Windows laptop and the existing production-origin iPhone transition have not been physically verified. Stop if saving, updating or reopening fails. No Android APK is included in this Windows/website release.
