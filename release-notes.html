What’s new in v2.7.1

Studio chartsPattern Creator (Beta)

Narrow Recycle Bin labels stay readable

Individual and bulk action labels wrap when a narrow panel or enlarged text leaves too little space. Complete labels and touch targets are preserved.

This release retains the feature set prepared for the unpublished v2.7.0 candidate. The preceding published release was v2.6.0.

Frame your photograph before making stitches

  • Choose the new 80 × 110 preset in Projects for 80 columns, 110 rows and 8,800 stitches.
  • Use Crop to Fill and move the proposed crop before confirming it.
  • Compare your framed photograph beside the actual stitch preview. Preview and Discard do not replace your saved stitches.
  • Use more grayscale shades and tonal controls, or choose optional Cartoon preparation. Photograph processing stays on your device.

More comfortable chart work

Type a zoom percentage, use more predictable wheel zoom, and keep helpful chart guidance outside the stitches. Responsive controls, collapsible tools and row-based crochet tracking make it easier to work on a phone, tablet or laptop. Existing stitch tracking, editing, Undo/Redo and Pattern Lock remain available.

Pattern Creator (Beta) and PDF Publisher (Beta)

Write original patterns, attach images, save reviewed frozen snapshots and export editable .deepattern backups. PDF Publisher supports Graph / Colorwork publications in Letter and A4. Other pattern families do not yet have every professional PDF layout.

Beta: These features are available to use and are still being improved. Back up important projects regularly. Experimental Keep Detail research is not included.

Downloads and updates

v2.7.1 release and instructions · Android APK · Windows ZIP

Keep the existing Android app installed and choose Update. On Windows, extract to a separate folder and retain the same browser profile and http://127.0.0.1:17828 address. Never clear app or browser storage to update.

Back up before updating

Keep external copies of Studio project ZIPs, Settings and Layout JSON, Written Pattern .deewritten files with their PDFs, and Pattern Creator .deepattern files. These are separate backup systems. A finished PDF is not an editable project backup. Store backups privately.

For website offline use, stay connected until Studio reports Ready for offline use, then check reopening offline. An intermittent Chromium first-install issue remains under investigation; refresh or retry while online if setup stops. Update checks and downloads may contact GitHub; image conversion does not upload your photographs.
